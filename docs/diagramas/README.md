## Cómo ver o editar los `.puml`

- **En línea:** pegar el contenido en [plantuml.com/plantuml](https://www.plantuml.com/plantuml).
- **draw.io:** Organizar → Insertar → Avanzado → PlantUML.
- **VS Code:** extensión *PlantUML* (jebbs.plantuml) y `Alt + D` para la vista previa. Requiere Java o un servidor PlantUML.
